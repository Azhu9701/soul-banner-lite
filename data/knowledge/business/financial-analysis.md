# 财务分析与经营指标

## 三张核心报表

### 资产负债表
反映企业在某一时点的财务状况，展示"企业有什么"和"欠谁的钱"。

**资产 = 负债 + 股东权益**

- **流动资产**：现金、应收账款、原材料库存、在制品、成品库存
- **固定资产**：工厂（不动产）、生产线（设备）
- **负债**：长期贷款、短期贷款、应付账款
- **股东权益**：股本、留存收益（历年净利润积累）

### 损益表（利润表）
反映企业在一段时期内的经营成果，展示"赚了多少"和"怎么赚的"。

**利润 = 收入 - 费用**

- **营业收入**：产品/服务销售收入
- **营业成本**：原材料成本、生产人工费用
- **毛利** = 营业收入 - 营业成本
- **营业费用**：销售费用、管理费用、研发费用、折旧
- **营业利润** = 毛利 - 营业费用
- **净利润** = 营业利润 - 利息 - 所得税

### 现金流量表
反映企业在一段时期内的现金流入和流出。

- **经营性现金流**：从生产到销售产品给客户的过程中赚钱的能力
- **投资性现金流**：投资、买卖设备和地产、利息收入等
- **融资性现金流**：借款、还款、发行股份、支付利息等

> **核心认知**：利润是"算出来的"，现金是"在手里的"。利润表可能显示盈利，但现金流断裂会导致企业破产。

## 关键财务指标

### 毛利率
反映产品的获利空间。

```
毛利率 = 毛利 ÷ 销售额 × 100%
```

- 毛利率低说明产品成本过高或定价过低
- 不同产品的毛利率应分别计算，找出最赚钱的产品线

### 销售净利润率
反映企业的费用管控能力。

```
销售净利润率 = 利润额 ÷ 销售额 × 100%
```

- 如果销售毛利高而净利润率偏低，说明管理费过高了

### 资产回报率（ROA）
反映企业运用全部资产创造利润的效率。

```
资产回报率 = 净利润 ÷ 总资产 × 100%
```

### 净资产回报率（ROE）
反映股东投资的回报率，是股东最关注的指标。

```
净资产回报率 = 净利润 ÷ 股东权益 × 100%
```

### 资产负债率
反映企业的偿付能力和财务风险。

```
资产负债率 = 总负债 ÷ 总资产 × 100%
```

- 比率过高说明负债风险大
- 比率过低可能说明没有充分利用财务杠杆

## 杜邦分析法

杜邦公式将 ROE 拆解为三个驱动因素：

```
ROE = 销售利润率 × 资产周转率 × 财务杠杆

即：净利润 ÷ 股东权益 =
    (净利润 ÷ 销售额) × (销售额 ÷ 总资产) × (总资产 ÷ 股东权益)
```

- **销售利润率**：盈利能力——每卖出一块钱能赚多少
- **资产周转率**：运营效率——一块钱资产能产生多少收入
- **财务杠杆**：资本结构——用多少借来的钱放大收益

> 杜邦公式的意义：帮助企业找到提升 ROE 的具体路径——是提升利润率、加快周转、还是适度增加杠杆。

## EVA 经济附加值

EVA 是衡量企业是否为股东创造真实价值的指标。

```
EVA = 税后净营业利润(NOPAT) - (加权平均资本成本(WACC) × 投资资本总额(TC))
```

- **EVA > 0**：企业在为股东创造价值
- **EVA < 0**：企业在毁灭股东价值（赚的钱还不够覆盖资本成本）

### 简化计算版

```
资本成本率：
  短期贷款  __M × 20% = __M
  长期贷款  __M × 10% = __M
  股  本    __M × 25% = __M
  合计      __M          资本成本率 = __%

EVA = 营业利润 - 税款 - (资本成本率 × 已用资本)
```

> EVA 超越了传统会计利润，考虑了股权资本的成本，是对企业真实经济利润的评价。

## 公司估值

企业经营的根本目的是创造价值。公司价值的估算方法：

```
公司价值 = 股本 + 去年净利润 + 今年净利润 × 2 + 新投资预期回报
```

其中，新投资预期回报指最近三年市场开发、产品开发和生产线建设总投资的 1/3。
