# 运营管理基础

## 研产销平衡

企业经营的核心在于平衡三个环节：

```
研发 → 生产 → 销售
  ↕      ↕      ↕
 产品开发  产能建设  市场需求
```

- **产能不足**：有订单但无法交付，失去市场机会
- **产能过剩**：投入大量资金建设但设备闲置，浪费资源
- **库存过多**：占用资金，增加仓储成本
- **库存短缺**：无法及时满足订单，影响市场排名

> 研产销平衡是企业经营中最复杂的挑战之一——这本质上是同时抛多个球的游戏。

## 产能规划

### 生产线类型对比

| 类型 | 建设时间 | 建设费用 | 特点 |
|------|---------|---------|------|
| 手工线 | 1季度 | 4M | 灵活可快速调整，但效率低 |
| 半自动线 | 4季度 | 2M/季度(共8M) | 效率和投资适中 |
| 全自动线 | 4季度 | 4M/季度(共16M) | 效率高但投资大 |

### 产品更换（转产）

- **手工线**：即刻更换，无成本
- **半自动线**：耗时1季度，投入1M
- **全自动线**：耗时2季度，投入2M/季度（共4M）

### 产能规划关键问题

1. **需要多少产能？** — 根据市场预测和订单量判断
2. **什么类型的产能？** — 灵活型 vs 高效型
3. **什么时候建设？** — 建设有时间周期，需提前规划
4. **产能部署在哪里？** — 靠近市场还是集中生产

## 供应链与库存管理

### 原材料采购

- 产品不同，原材料价格不同
- 原材料订单需提前下达（订单不可撤销）
- 原材料采购不足 → 生产停顿
- 原材料采购过多 → 资金积压

### 原材料价格

| 产品 | 原材料成本/个 |
|-----|-------------|
| 基础产品（奔马） | 1M |
| 升级产品（猛虎） | 2M |
| 中级产品（飞鹰） | 3M |
| 高级产品（天龙） | 4M |

### 生产费用

| 产品 | 生产费用/批 |
|-----|------------|
| 基础产品（奔马） | 1M |
| 升级产品（猛虎） | 1M |
| 中级产品（飞鹰） | 2M |
| 高级产品（天龙） | 2M |

### 库存管理原则

- 成品库存：应对需求波动，但占用资金
- 原材料库存：保障生产连续性，但存在跌价风险
- 在制品库存：不可避免，但要控制在合理水平

## 资本周转

### 基本规律

```
规律一：产品的基础价值 = 原材料成本 + 生产人工费用

规律二：如果客户愿意付出更高的价格，经营就产生了毛利

规律三：管理一家企业就是管理它的资本周转
```

### 资本周转链

```
现金 → 原材料采购 → 生产加工 → 成品库存 → 销售 → 应收账款 → 现金
  ↑                                                                 |
  └──────────────────── 一个完整的周转周期 ────────────────────────┘
```

### 周转周期的重要节点

1. **原材料库存天数**：从采购到投入生产
2. **生产周期**：从投入到产出成品
3. **成品库存天数**：从产成品到销售出库
4. **应收账款账期**：从交货到收到货款

### 改善资本周转的途径

- **加快生产速度**：缩短生产周期
- **降低库存水平**：减少资金占用
- **优化应收账款管理**：缩短回款周期
- **提高固定资产使用率**：让每条生产线都发挥最大效能

## 现金流管理

现金流管理关乎企业生死，马虎不得。

### 现金流三大分类

| 类型 | 描述 | 常见项目 |
|------|------|---------|
| 经营性现金流 | 核心业务产生的现金 | 销售回款、原材料采购、工资、税费 |
| 投资性现金流 | 投资活动产生的现金 | 建生产线、买工厂、出售资产 |
| 融资性现金流 | 融资活动产生的现金 | 贷款、还款、发行股票 |

### 现金流紧张时的应对

1. **应收账款贴现**：用应收账款换取现金（需支付1/14的服务费）
2. **短期贷款**：补充短期流动性（年利率10%）
3. **出售固定资产**：出售工厂或生产线换取现金
4. **削减费用**：压缩不必要的开支

### 融资原则

- **长贷**（年息5%）：用于长期投资，如生产线建设、市场开发
- **短贷**（年息10%）：用于短期周转，如原材料采购
- **贷款总额度** = 上年度净资产 × 4（长贷2倍 + 短贷2倍）
- **最低起贷**：20M，只能贷20M的倍数

## 市场与销售管理

### 订单获取机制

1. **营销投入激活订单**：每1M的销售投入"激活"一张订单（有上限）
2. **优先选单权**：上年度此市场销售额最高的公司优先挑选订单
3. **选单顺序**：其他公司按销售费用投入多少依次选单

### 市场维护

- 已开发市场每年至少投入1M，才能保留未来拿订单的机会
- 如果在某个市场不做投入，视为离开此市场
- 离开后想返回需要等待

### 延期交付的惩罚

- 客户只会支付75%的货款
- 公司在本市场的排名下降一位
- 紧急订单必须在第一季度交货，否则同样受罚

## 年度经营流程

### 年初决策
1. 是否做新市场投资
2. 是否购买/租赁工厂
3. 是否做新的长期贷款
4. 确定竞标策略
5. 参与订货会

### 季度运营（每季度循环）
1. 更新应收账款
2. 更新短期贷款并支付利息
3. 投资产品开发
4. 供应商交货并支付原材料费用
5. 发出新的原材料采购订单
6. 更新生产状态
7. 产能升级/产品转产
8. 原材料上线并支付生产费用
9. 订单交付/应收账款入账
10. 支付行政管理费用（1M/季度）

### 年末收尾
1. 支付生产线管理费用（1M/条）
2. 固定资产折旧（20%/年）
3. 更新长期贷款、支付利息
4. 缴纳税款（营业税3% + 所得税20%）
5. 编制年度财务报表
