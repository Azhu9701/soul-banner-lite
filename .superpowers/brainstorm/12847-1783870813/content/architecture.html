技术可行性评估

✅

REST API 通信

Godot 内置 HTTPRequest 节点，直接调 Rust API 的 JSON 接口。数据格式完全复用现有模型。难度：低

✅

WebSocket 实时流

AI 回复需要流式传输（SSE/WebSocket）。Godot 内置 WebSocket 客户端，可对接 Rust 的 ws 端点。难度：中

⚠️

3D 法庭/场景渲染

Godot 的强项。需要建模（法庭、会议室、商业沙盘桌）。可买现成 3D 模型或简单几何体起步。难度：中（美术工作量）

✅

用户认证与会话

完全由 Rust 后端管理，Godot 只需存 token。无额外复杂度。难度：低

⚠️

多人同庭（可选）

Godot 内置多人游戏支持（ENet/WebSocket）。如需多人实时参与同一庭审，需后端新增中继逻辑。难度：中-高

✅

跨平台发布

Godot 一次开发 → 导出 Windows / Mac / Linux / Web / Android / iOS。Web 版可替代现有网站。难度：低
